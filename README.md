# 🧠 CNN CIFAR-10 Image Classification

This repository contains a Convolutional Neural Network (CNN) implemented using TensorFlow/Keras to classify images from the CIFAR-10 dataset.

The project demonstrates dataset loading, CNN architecture design, training, evaluation, and prediction visualization.

---

## 🚀 Features

- CNN architecture built from scratch
- CIFAR-10 dataset loading
- Image normalization
- Model training and evaluation
- Accuracy visualization
- Single image prediction support

---

## 🛠 Tech Stack

- Python  
- TensorFlow / Keras  
- NumPy  
- Matplotlib  

---
## 🧠 Training

### Training Configuration

- **Dataset:** CIFAR-10  
- **Image Size:** 32 × 32 RGB  
- **Batch Size:** 64  
- **Epochs:** 10
---
### 🔄 Training Process

1. Load CIFAR-10 dataset  
2. Normalize images  
3. Build CNN model  
4. Compile model  
5. Train on training data  
6. Evaluate on test data  
7. Visualize predictions  

- **Optimizer:** Adam  
- **Loss Function:** Sparse Categorical Crossentropy  
- **Metrics:** Accuracy
---

The script displays:
